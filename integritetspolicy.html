1. Personuppgiftsansvarig

Juridify AB, organisationsnummer 559566-5752, med säte i Göteborg, är personuppgiftsansvarig för behandlingen av personuppgifter som beskrivs i denna policy. Kontakta oss på info@juridify.se vid frågor om hur vi hanterar era personuppgifter.

2. Vilka uppgifter vi samlar in

Vi samlar in de personuppgifter ni själva lämnar till oss, till exempel via kontaktformuläret på juridify.se eller vid bokning av möte. Det kan handla om:

  • Namn, e-postadress och eventuellt telefonnummer
  • Företagsnamn eller organisation
  • Information om ert ärende, inklusive uppgifter ni lämnar i formulärets fritextfält
  • Uppgifter som lämnas vid bokning av möte via vår bokningskalender

4. Mottagare av personuppgifter

För att driva webbplatsen och hantera förfrågningar använder vi ett antal utomstående tjänsteleverantörer som kan komma att behandla personuppgifter för vår räkning:

  • GitHub Pages — hostingtjänst för webbplatsen. GitHub kan i sina serverloggar registrera besökares IP-adress.
  • FormSubmit — vidarebefordrar innehållet i kontaktformuläret till vår e-post.
  • Calendly — hanterar bokning av möten.
  • Google Fonts — laddar typsnitt till webbplatsen, vilket innebär att er webbläsare gör en förfrågan till Googles servrar.

Vi delar inte personuppgifter med tredje part för marknadsföringsändamål.

5. Lagringstid

Uppgifter som lämnas via kontaktformuläret sparas så länge det behövs för att hantera er förfrågan, och därefter i enlighet med bokföringslagens krav för uppgifter kopplade till fakturerade uppdrag (normalt sju år).

6. Era rättigheter

Enligt Dataskyddsförordningen (GDPR) har ni rätt att:

  • Begära tillgång till (registerutdrag) de personuppgifter vi behandlar om er
  • Begära rättelse av felaktiga uppgifter
  • Begära radering av uppgifter, i den mån det inte strider mot annan rättslig förpliktelse
  • Invända mot eller begära begränsning av behandlingen
  • Begära dataportabilitet

Ni har även rätt att lämna klagomål till Integritetsskyddsmyndigheten (IMY) om ni anser att era personuppgifter behandlas felaktigt.
